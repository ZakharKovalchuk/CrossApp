# CrossApp

Наскрізний навчальний проєкт з дисципліни «Крос-платформне програмування».

## Предметна область: Бібліотека
- **Призначення**: Облік каталогу видань, фізичних примірників книг, реєстрація читачів та контроль процесів видачі й повернення літератури.
- **Основні сутності**:
  - `Book` — бібліографічний запис видання (назва, автор, ISBN, рік).
  - `BookCopy` — конкретний фізичний примірник книги з унікальним інвентарним номером і поточним статусом доступності.
  - `Reader` — читач бібліотеки (ПІБ, номер квитка, контактні дані).
  - `Loan` — запис операції видачі книги (посилання на читача, примірник, дата видачі, плановий і фактичний терміни повернення).
